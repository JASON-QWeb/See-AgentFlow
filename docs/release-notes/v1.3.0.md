沉浸模式加入连续变速。日志与粒子会随多个节拍减速、逐渐加速或短促提速。双屏共用同一时钟，回放继续使用本地历史，实时指标仍来自观察器。

同时改进了 macOS 原生交互和快捷键。

## 安装

需要 Apple Silicon 和 macOS 26 或更高版本。安装包自带运行时。

下载 DMG，将 App 拖入「应用程序」并打开一次。具体步骤见[安装说明](https://github.com/JASON-QWeb/See-AgentFlow/blob/v1.3.0/docs/TECHNICAL.md)。

下载后可在同一目录校验安装包。

```bash
shasum -a 256 -c See-AgentFlow-1.3.0-arm64.dmg.sha256
```
