# Agent Ops 原生 App / 屏保

这是原生 AppKit / WKWebView App，内含 macOS 屏保扩展、只读采集器和独立 Node 运行环境。DMG 安装时拖入 Applications，弹出磁盘映像后打开 App 一次；界面、采集与后台配置都在本机运行，无需另装 Node。

## 桌面悬浮窗

- 打开 App 默认显示原版看板悬浮窗，置顶但可以正常操作其他应用。菜单栏图标右键菜单的 `Always on Top` 默认勾选；取消后窗口可被其他窗口覆盖，重开 App 会恢复所选层级。
- 登录时通过用户级 LaunchAgent 静默启动菜单栏，不弹出窗口、不创建浮窗渲染器；从菜单栏选择显示悬浮看板即可打开。采集器独立常驻，关闭窗口或退出菜单栏 App 不会停止采集服务。
- 拖动上沿移动，拖动边缘/角调整大小；无可见标题与白色标题栏，右上沿使用单色最小化、缩放和关闭控件，悬停时增强显示。`Window` 菜单也保留这些操作，`⌘W` 关闭、`⌘M` 最小化。
- 最小窗口 560×400；宽不足 1120 或高不足 700 个 macOS 点时，底部四块面板卸载，腾出动画区域。放大至两项均满足后恢复。阈值按原生窗口尺寸计算，不受页面缩放影响。位置、尺寸和展示偏好保存在本机。
- App 运行时，`⌘L` 可从其他应用锁定所有屏幕并自动选择布局，无需辅助功能或输入监控权限。App 获得焦点时，`⌘0` 显示悬浮窗，`⌘S` 锁定所有屏幕并使用原版布局。需先设置密码。解锁后可按 `⌘Q` 退出 App。
- 关闭悬浮窗会释放 WebView，但保留菜单栏入口；最小化也释放渲染器。
- 收到锁屏、屏保启动或显示器休眠通知后，悬浮窗隐藏并释放 WebView。解锁/屏保结束后恢复用户原先可见的悬浮窗；关闭过的窗口不会擅自重开。
- 全屏预览时释放悬浮窗，返回桌面时释放所有全屏 WebView，避免同时渲染两套画面。
- Settings 内可切换 `Mint Terminal / Silver Stream / White Signal`；白色主题保留深色背景，以不同粗细的白色、银色和灰色流线为主。语言可选 English、简体中文、繁體中文，默认英文。选择通过本机服务保存并同步到浏览器、悬浮窗和屏保；原生菜单在下次打开时更新语言，真实日志及会话名称保留原文。

## 双屏

单显示器使用原版 `DispatchScene`，不改变原有元素位置。多显示器读取 `NSScreen` 的真实排列与偏移，组合成共享画布；每个屏幕仅渲染自己的物理视口。

双屏使用放大、压扁的八字莫比乌斯环，每个环瓣约占对应屏幕的一半宽度。更大的日志文字和加粗流线配合左右独立方向的分发；环内曲线轻微变形，带短拖尾的文件光点沿曲线穿行。环带文字来自实际历史日志；十六进制块由这些文字的 UTF-8 字节生成。展示光流不进入采集计数。两屏使用同一个绝对时间周期和确定性粒子种子，环带纹理也按统一时间段换页。

光流在 GPU 顶点着色器计算，文件光点固定上限 720（外部 512、环内 208），不逐帧读盘或上传粒子缓冲。每个画布最高 3840×2160 像素预算；每屏尊重自身 Retina 比例、60 FPS 上限、暂停、节能与减少动态效果。隐藏页面停止绘制并断开页面 SSE。

## 屏保与安装

App 内含 `AgentOpsSaver.appex`，首次启动向 PluginKit 注册。安装后在系统设置的墙纸 / 屏幕保护程序中确认选择 **Agent Ops · Continuous Link**，并设置空闲启动时间。可用 `open -a ScreenSaverEngine` 手动触发，观察至少 15 秒再退出。屏保与密码认证由 macOS 控制；不替换系统登录界面，不承诺锁屏按键触发后立刻显示动画，显示器关闭时也不会继续显示。锁屏密码与显示器休眠设置未修改。

屏保自动采用高画质沉浸模式，最高 60 FPS，保留 4K 像素预算与真实历史回放标记。单屏和双屏均隐藏顶部工具栏、设置与节能开关，事件查看弹层也不会在屏保中打开；主题、语言等配置从桌面 App 调整。

从旧开发安装迁移到 `/Applications` 后，WallpaperAgent 可能仍缓存旧模块路径，实际启动时会报 `Failed to find screen saver module` 并把选择重置为系统默认。确认只剩正式安装版，重新注册其扩展后，用 `killall WallpaperAgent` 刷新宿主（桌面墙纸会短暂重绘），再从系统设置选回 Agent Ops。仅检查设置中的选中状态不足以证明实际启动成功。

1.1.1 修复了屏保进入后变白的问题：macOS 的远程屏保窗口被 WebKit 误判为遮挡，加载成功后约三秒便冻结并移除图层。兼容处理仅在 `local.agentops.saver.extension` 中关闭 WebKit 的窗口遮挡检测；仍由原生屏保生命周期在结束、休眠和移除视图时释放渲染器。桌面浮窗与浏览器的隐藏停绘机制保持原样。该 WebKit 私有兼容接口有运行时可用性检查，后续系统升级仍需实测。

1.1.2 为长时间运行增加预览过期回收、限量回放替换与双屏读取合并。隐藏页面 15 秒后释放显示缓存和 Canvas/WebGL 资源，重新可见时恢复；退出立即释放。单屏粒子坐标复用，减少逐帧临时分配。保留原始日志、已有布局和屏保的高画质沉浸模式。

开发构建与更新：

```sh
npm run build:saver
python3 macos/install.py
npm run build:dmg
npm run test:installer
```

首次启动将包内运行环境复制到 `~/Library/Application Support/Agent Ops/runtime`，注册 `~/Library/LaunchAgents/local.agentops.observer.plist` 及 `local.agentops.desktop.plist`。采集器登录后启动，优先级 `nice +10`、低优先级 I/O，只监听 `127.0.0.1:4318`。未变化的运行文件不会反复复制或重启；更新先暂存，再替换，启动失败时恢复上一版和服务定义。源日志与用户偏好在更新事务之外。开发安装脚本使用相同启动流程，目标为 `~/Applications`。

DMG 针对 Apple Silicon / macOS 26+，使用 Xcode、Swift 编译和 ad-hoc 签名，尚未经过 Apple 公证。包内 Node 保留 Node.js Foundation 签名与许可证。安装到另一台兼容 Mac 后读取那台机器当前用户的本地日志；安装包不包含开发机器的日志、设置或认证文件。

卸载：`python3 macos/uninstall.py` 停止本用户的两个后台服务，注销已安装屏保扩展，将 App、服务定义及运行文件移入废纸篓。主题/语言文件、窗口偏好和原始 Codex / Claude 日志保留。

开发安装的旧版本以 ZIP 保存，避免系统把备份当作另一个 App。DMG 校验成功或开发安装完成后，会注销并移除未安装的构建副本；保留 DMG 及正式安装版。`npm run build:saver` 单独运行时仍会生成供开发检查的 App。

现代屏保扩展宿主的少量类声明未包含在公开 SDK 中，集中隔离在 `ScreenSaverBridge.h`。此兼容方式参考维护者的 [macOS 屏保扩展文档](https://aerialscreensaver.github.io/developers/appex-distribution/)，未来系统升级可能需要适配；没有关闭 Gatekeeper 或修改锁屏认证设置。

## 1.2.0 应用全屏锁定

桌面 App 设置新增 Fullscreen Lock，首次由用户自行输入密码（无默认密码）。密码输入使用原生安全文本框，保存到 `~/Library/Application Support/Agent Ops/app-lock.json` 的内容仅为随机盐与 210,000 次 PBKDF2-SHA256 校验值，文件权限为 0600。该文件不会进入 DMG、仓库或日志接口。改密码需要当前密码。

全屏按钮、`⌘L` 和「锁定全部屏幕」菜单都会为每块物理屏幕建立无边框置顶窗口。点击密码框右上角的 ×，或连续两分钟未编辑密码，会清空输入并隐藏密码框，继续显示锁屏画面。按回车或点击任一锁屏画面可重新输入密码。输入正确密码或连续点击密码框标题 10 次可返回桌面，点击间隔超过 3 秒会重置计数。五次错误校验后短暂限流。原生密码框在观察服务不可用时仍可操作。macOS 保留自身的密码认证。

设置密码后，屏保结束自动进入应用锁定默认开启。系统锁屏或显示器休眠期间，应用释放自己的渲染器并让出系统认证界面；返回桌面后重新覆盖所有屏幕。插拔显示器会重新计算覆盖范围。后台登录保持静默，未设置密码时不会主动遮挡桌面。

`npm run test:native-lock` 使用临时校验文件和不可见窗口验证密码修改、锁定状态事件顺序、两屏覆盖、备用入口、错误限流和窗口释放；不改变主屏显示、系统密码或用户密码配置。
